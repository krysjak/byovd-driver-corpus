У репозиторії зібрано драйвери ядра Windows і дані для їх дослідження: хеші файлів, відомості про підписи, PE-імпорти, результати статичного аналізу та посилання на відкриті джерела про BYOVD.

**Це колекція кандидатів, а не перелік драйверів із доведеною можливістю експлуатації.** Результати аналізу допомагають визначити, які файли варто перевіряти детальніше.

## Як формувався корпус

1. **Збір.** Пошук драйверів у OEM-пакетах, архівах виробників, Windows Update, відкритих колекціях та на реальних системах.
2. **Витягнення.** Отримання файлів `.sys` з архівів і інсталяторів `.zip`, `.cab`, `.7z`, `.exe`.
3. **Аналіз.** Збереження PE-метаданих, MD5/SHA-1/SHA-256, імпортованих функцій та ознак створення device object, symbolic link і поверхні IOCTL.
4. **Звірка.** Порівняння з LOLDrivers та блоклистом вразливих драйверів Microsoft; розрахунок евристичної оцінки для пріоритизації перевірок.

Два файли перевищують ліміт GitHub у 100 МБ і не включені до репозиторію як бінарники: `nvlddmkm.sys` та `amdkmdag_1.sys`. Записи про них залишилися в індексі.

## Як тлумачити результати

`byovd_score` — це **евристичний показник для пріоритизації досліджень**, а не оцінка підтвердженої вразливості. Наявність імпорту функції роботи з пам’яттю сама по собі не означає, що драйвер надає небезпечний доступ непривілейованому процесу.

Позначка `signed` спирається на зібрані дані про підпис; під час пакетного аналізу **не перевірялася довіра до кожного ланцюжка сертифікатів**. Збіг із LOLDrivers необхідно перевіряти за точним хешем і першоджерелом. Відсутність збігу з блоклистом Microsoft нічого не доводить щодо безпечності драйвера.

Файл з індикаторами — матеріал для аналізу, **а не готовий список для автоматичного блокування**. Перед застосуванням правил у робочому середовищі перевіряйте хеші, контекст і можливі хибні спрацювання.

## Призначення та відповідальне використання

Корпус створено для розробки детектів, threat hunting, інвентаризації драйверів і дослідження вразливостей. Він не замінює ручного реверс-інжинірингу та контрольованої перевірки.

Права на бінарні файли належать відповідним правовласникам; їхня присутність у колекції не надає додаткових прав на розповсюдження. Не запускайте невідомі драйвери у продуктивних системах.

Щоб повідомити про помилку в метаданих, питання авторства чи необхідність видалення файлу, [створіть issue](https://github.com/krysjak/byovd-driver-corpus/issues).
